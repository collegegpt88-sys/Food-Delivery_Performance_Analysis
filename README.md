# Food-Delivery_Performance_Analysis

## 📊 Project Overview
This project analyzes food delivery operations to identify key factors affecting delivery time and operational efficiency. The goal is to uncover patterns that impact delivery performance and provide data-driven insights to improve customer satisfaction.

The analysis reveals that **distance and traffic are the primary drivers of delivery delays**, while **weather conditions further influence delivery time**. Additionally, **vehicle type plays a role in efficiency**, with scooters performing better in urban environments.

## 🛠️ Tools & Technologies
- Python (Pandas, Matplotlib, Seaborn)
- SQL (MySQL)
- Power BI

## 📂 Dataset Summary
- Initial Data: 1001 records, 9 columns  
- After Cleaning: 975 records, 12 columns  
- Missing Values Handled: ~90

### Engineered Features:
- Distance_Category

## 📈 Key Insights
- 📍 Distance is the most critical factor affecting delivery time  
- 🚦 High traffic significantly increases delivery delays  
- 🌧️ Weather conditions like rain and snow slow down deliveries  
- 🛵 Scooters are the most efficient delivery vehicles  
- 👤 Courier experience has minimal impact compared to external factors  

## 📊 Dashboard Highlights (Power BI)

## 💡 Business Recommendations
- Optimize routes for long-distance deliveries  
- Use scooters in high-traffic urban areas  
- Improve delivery planning during peak hours  
- Implement weather-aware delivery strategies  

## 🚀 Conclusion
This project demonstrates how data analytics can be used to identify operational inefficiencies and improve delivery performance. By leveraging Python, SQL, and Power BI, it provides an end-to-end analytical solution for real-world business problems.
